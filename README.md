# Introduction to Machine Learning for Water Professionals

A hands-on machine learning course designed for water sector professionals, covering fundamental ML concepts and practical applications in hydrology and water resource management.

## Course Structure

### Module 1: Data Fundamentals
- [Data Analysis](module_1/1_4_Data_analysis.ipynb)
- [Data Transformation](module_1/1_5_Data_transformation.ipynb)

### Module 2: Classification
- [Classification](module_2/2_Classification.ipynb)

### Module 3: Regression
- [Regression](module_3/3_Regression.ipynb)

### Module 4: Neural Networks
- [Neural Networks](module_4/4_neural_networks.ipynb)

### Module 5: Time Series
- [Time Series Processing](module_5/5_1_Time_series_processing.ipynb)
- [Time Series Forecast](module_5/5_2_Time_series_forecast.ipynb)

### Module 6: Convolutional Neural Networks
- [Convolutional Neural Networks](module_6/6_convolutional_neural_networks.ipynb)
- [Water Mapping](module_6/6_water_mapping.ipynb)

### Assignment
- [Assignment](Assignment/Assignment.ipynb) - Predict average annual river discharge using hydrological data

## Getting Started

Work through modules sequentially. Each module builds upon previous concepts following the ML workflow: data preparation → model training → evaluation → iteration.

Solution notebooks are provided for modules 1-4.

## Requirements

- Python 3.x
- Jupyter Notebook
- Key libraries: pandas, numpy, scikit-learn, matplotlib
